# Liquid Folders

Make your macOS folders Liquid Glass

https://github.com/user-attachments/assets/a6c25acf-bcd0-4c5b-b83d-fe039ed1743f

> Requires macOS 26 (Tahoe) or later, on Apple silicon or Intel

## Installation

### npm

```sh
npm install liquid-folders
```

### Homebrew

```sh
brew trust zupersun/tap
brew install --cask zupersun/tap/liquid-folders
```

### Build from source

```sh
git clone https://github.com/zupersun/liquid-folders.git
cd liquid-folders
./build.sh
cp -R ".build/Liquid Folder.app" /Applications/
```

Then open Liquid Folder from Applications.

## Usage

On first launch, allow Liquid Folder in **System Settings** → **Privacy & Security** → **Accessibility**.

then **Right-click** → **Quick Actions** → **Liquify**

- New folders on automatically liquify
- Toggle on and off from the menu bar icon
